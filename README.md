# Maya AI — iPhone Web Edition

A browser-based Maya AI interface using the Maya glowing-ring animation.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `assets/maya_animation.gif`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will give you a public website URL.

## Important

This is a browser edition. It does not run the original macOS Python/Ollama code inside iPhone Safari. Full AI chat with Ollama requires a backend/API connection.
